# МСО74 — железо

Плата контроллера, корпус поста и документация отладочной платы. Прошивка — `mso-firmware`, сервер — `mso-server`,
ферма — `mso-farm`. Сюда можно давать доступ разводчикам и конструкторам без доступа к коду.

| Папка | Что там |
|---|---|
| `plata/` | своя плата контроллера: ТЗ (`TZ.md`), дальше — схема, разводка, Gerber и BOM по ревизиям (`rev_A/`, `rev_B/`…) |
| `korpus/` | корпус поста: эскизы модулей, чертежи и файлы резки (`chertezhi/modul_tablo/` — модуль табло, в работе) |
| `a147/` | документация отладочной платы A147 (стенд): схемы производителя |

Как подключается периферия к контроллеру и что делает прошивка (MDB, монетник) — `mso-firmware/docs/MDB.md`.
