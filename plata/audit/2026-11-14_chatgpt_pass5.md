```bash

python3 plata/audit/pass5/gpio_check.py ../mso74-plata.xml
python3 plata/audit/pass5/calculate.py
```
По исходному XML: **316 компонентов, 266 цепей, 305 выводов ИС, 101 контакт разъёмов J, 35 одноузловых цепей — все явно NC, 0 неожиданных**. Наличие метки NC не доказывает, что её разрешает даташит. Скрипт экспортирует `results/ic_pins.csv` для всех 21 микросхем (номер, имя, цепь, footprint), `connectors.csv`, `single_nets.csv`, `diodes.csv`, `direct_ic_pins.csv`, `conductive_edges.csv`, `dc_paths.csv`. Граф путей учитывает только пассивные DC-ветви и диоды в прямом направлении, **не** учитывает транзисторы, ESD и состояние микросхем; достижимость не равна опасному току.

**GPIO:** все 36 назначенных GPIO совпали с PINOUT.md, GPIO45/46 явно NC, 0 несовпадений.
